# IK17_KG — measuring-point readings

File `data/IK17_KG.parquet`, 729,886 rows. One row is one reading of one measuring point, normally
taken during an inspection order. A point is read again and again: 30,964 points, 12,846 orders,
1,589 functional locations; a point belongs to one location. A point can be read more than once on
the same day in the same order, so rows and distinct points differ — see [../rules.md](../rules.md).

| Column | Type | Holds |
| --- | --- | --- |
| `order` | VARCHAR | the inspection order (quote it: `"order"`); empty on 106,533 rows — a data-entry defect, readings reported without an order |
| `reading` | DOUBLE | the measured value; present on 151,779 rows only — most points are judged, not measured |
| `functional_location` | VARCHAR | where the point is; its 2nd segment is the plant ([keys.md](keys.md)) |
| `created_on` | DATE | the day of the reading; the date for "in a month" |
| `point` | VARCHAR | the measuring point number |
| `text_code` | VARCHAR | the result: `OK`, `Not OK`, `Performed`, `Not performed`, `Not checked`, … ([codes.md](codes.md), under the reading result) |
| `lower_limit` | DOUBLE | lower limit of the reading, where set (641,855 rows) |
| `upper_limit` | DOUBLE | upper limit of the reading, where set (144,027 rows) |
| `units` | VARCHAR | unit of `reading` ([codes.md](codes.md)) |
| `order_status` | VARCHAR | the order's system status: `TECO` closed as performed (623,191), `REL` still open (162), empty where there is no order |

"Points not performed" are `text_code IN ('Not performed', 'Not checked')`. A reading outside its
limits is `reading < lower_limit OR reading > upper_limit` (13,274 rows).
