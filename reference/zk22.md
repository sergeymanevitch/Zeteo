# ZK22_KG — material costs

File `data/ZK22_KG.parquet`, 547,801 rows. One row is one material consumption booked on a
maintenance order: the material issued and its value. A negative row is a return — the plant gave
back material it did not use. 121,072 orders, 5,938 functional locations.

| Column | Type | Holds |
| --- | --- | --- |
| `order` | VARCHAR | the maintenance order (quote it: `"order"`) |
| `date` | DATE | the posting day; the only date, and the one for "in a month" |
| `quantity` | DOUBLE | quantity issued; negative on a return (15,751 rows); 0 on 38,936 value-only rows |
| `cost` | DECIMAL(18,2) | the cost of the whole line, not a unit price (Sergey); the amount is in `quantity`; negative on a return or a value credit (33,014 rows) |
| `functional_location` | VARCHAR | where the material went; its 2nd segment is the plant ([keys.md](keys.md)) |

"The cost" of something is the net `sum(cost)`, returns included. Bookings and their reversals can
be very large and cancel out: order `1000097414` on 2021-01-26 holds +439,717,316.60 and
−439,717,316.60. When a period holds returns, give the booked (`cost > 0`) and returned
(`cost < 0`) sums beside the net.
