# ZW38_KG — maintenance orders

File `data/ZW38_KG.parquet`, 70,241 rows. One row is one maintenance order. There is no order
number and no functional location: an order is found by its plant, work center, type, priority,
statuses and dates, and counted as rows.

| Column | Type | Holds |
| --- | --- | --- |
| `closed_on` | DATE | the closing day on orders with `TECO`; on the 7,748 orders without it the value runs into the future (to 2027-11-18), so it is no completion date there |
| `order_type` | VARCHAR | `RPM1` maintenance, `RPM2` preventive, `RPM3` safety, `RPM7` RCA, `1126` undocumented ([codes.md](codes.md)) |
| `created_on` | DATE | the day the order was created; the default for "orders in a month" ([keys.md](keys.md#dates)) |
| `released_on` | DATE | the day the order was released; empty on 6,936 rows |
| `actual_end_date` | DATE | the actual end; it equals `scheduled_end_date` when the order was done on its scheduled day, which is 70,238 of 70,241 rows |
| `scheduled_end_date` | DATE | the scheduled end |
| `actual_start_date` | DATE | the real start of work; empty on 54,983 rows |
| `priority` | INTEGER | urgency 1–6 ([codes.md](codes.md)); empty on 33,187 rows, mostly preventive orders |
| `actual_start_date_2` | DATE | a second column the export also named actual start; equals `scheduled_start_date` on 70,239 of 70,241 rows |
| `scheduled_start_date` | DATE | the scheduled start; the date for "orders planned for" a day or a month ([keys.md](keys.md#dates)) |
| `main_work_center` | VARCHAR | the work center: 19 values, each beginning with its plant's digits ([keys.md](keys.md#plant)) |
| `user_status` | VARCHAR | the plant's status, codes separated by one or two spaces ([codes.md](codes.md)) |
| `required_end_date` | DATE | the required end; empty on 31 rows |
| `system_status` | VARCHAR | SAP system status, codes separated by spaces ([codes.md](codes.md)) |
| `plant` | VARCHAR | the plant: `13`, `32`, `43`, `56`, `64`, `65`, `88`, `8100` |

For "when did the work actually start", use `actual_start_date` and say how many orders have none.
